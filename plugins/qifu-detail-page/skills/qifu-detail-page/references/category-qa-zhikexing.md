## 页面结构

- 画板固定 1366 × 768，复用当前文件中已核验的智客星 Header、Logo、侧栏、工作区页签、主题变量和本地 Text Style。只复用平台外壳，不把列表 Filter Bar、Table 或 PageHead 作为本组合主体。
- 只允许 `platform=zhikexing`；不得解析或保留 yushu、毓数、鲸数或 QBI 的 Header、Logo、变量、菜单或组件主引用。Header 使用 `Navigation / HeaderMenu / 智客星 Header` 的真实 `INSTANCE`，侧栏沿用智客星 `copyTemplate` 外壳。
- 页面背景和白色内容面板沿用智客星适配器的外层规则；必须保留三层导航，不把它们合并：平台侧边导航、顶部工作区页签、业务页签。
- 本场景侧栏只使用**单列二级菜单**：`团队辅助 > 团队审核` 展开且当前选中；客户管理按业务需要使用单列展开或收起态，首页、系统管理保留。不得生成两列二级菜单、双栏叶子网格或 100px 宽缩放菜单。当前叶子有浅绿色背景和右侧绿色指示条，选中祖先的标题、图标、展开指示器均为主题色；未选中父项使用中性色与对应收起状态实例。
- 工作区页签固定为 `首页`、`团队审核`，后者为选中态，具有既有选中底色、状态标记和关闭图标。业务页签固定为 `话术审核`、`模型话术`；后者使用深色加重文字和**短线居中**的绿色指示线，不沿用列表页“指示线等于标题文字宽度”的规则。
- 内容面板使用页面级 Auto Layout：左侧约 200px 类目栏，右侧自适应筛选与问答区；两栏由浅色分隔线区分。类目栏不是平台侧栏，也不是 `Master Detail` 的固定 320px 实体列表。
- 类目栏的内边距、搜索与列表留白按截图分层处理，不能把内容区统一为单一 padding。搜索图标必须位于真实 Input 内部；类目图标、标题、数量使用稳定三列对齐。默认类目为 `会员问题（74）`，其余类目按输入给定顺序渲染。
- 右侧筛选区先解析 Input、Select、Search、Button 的真实实例；最近一次更新时间、最近一次更新人、问题搜索与查询/重置在同一行、同高度。控件组位于左侧，查询/重置固定靠右，其间使用弹性 Spacer，不能用固定空白矩形硬撑。
- 问答层级为 `分组 > 问题 > 回答`。分组与问题各自使用真实 `Data Display / Collapse / Panel` 状态实例，页面级 Auto Layout 承载两层嵌套和多条只读回答；回答是内容文本，不冒充控件。
- `Collapse / Panel` 组件集位于同文件节点 `3242:146`，其展开内容当前是固定文本实例，没有嵌套 Slot。必须先验证实例的合法可见性/尺寸覆写和页面级组合可承载嵌套内容；不能直接把子问题写进固定文本 Slot，也不能分离实例或手绘折叠控件。若验证失败，报告 `BLOCKED_COMPONENT_GAP`，不得生成假两级折叠。
- 默认状态仅展开第一个问题分组，以及其中两个具体问题；`询问如何退会员`、`退会员的钱退到哪里` 默认收起。展开/收起图标必须与真实状态匹配。
- 分组标题为浅灰底，左侧为折叠图标和标题，右侧依次为更新人、更新时间、操作日志链接；问题标题相对分组再缩进，采用浅灰底和加重文字；回答继续缩进并以细分割线分隔。不得压成单级折叠、表格或聊天气泡。
- 超过可见高度时仅问答内容区域滚动；画板仍保持 768px。回答以明确的单行文本容器实现省略，保留截图中可识别的文字和省略位置，不缩小字号硬塞或补写不可识别的业务规则。
