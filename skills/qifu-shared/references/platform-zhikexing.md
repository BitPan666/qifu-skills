## 1. 平台标识

```yaml
adapter:
  id: platform-zhikexing
  displayName: 智客星
  generationStrategy: copyTemplate
  theme:
    primary: '#00B578'
  shell:
    header:
      componentSet: Navigation / HeaderMenu / 智客星 Header
      sourceNode: '5517:2109'
      height: 48
      variantProperty: Items
      defaultVariant: '0'
    sidebar: 模板内置智客星 SideNavigation（200px）
```

- `platform=zhikexing` 时，`generationStrategy` 固定为 `copyTemplate`，不得改回 `assemble`。
- 智客星 Header 使用专属 `Navigation / HeaderMenu / 智客星 Header` 组件集；解析到 `Yushu Header-V2`、毓数 Logo 或毓数 HeaderMenu 时，必须停止并返回 `BLOCKED_PLATFORM_COMPONENT_INTEGRITY`，不得借用或回退。
- SideMenu 继续由复制基线模板整体获得，不逐项组装。

## 2. 生成策略

`copyTemplate` 与毓数的 `assemble` 是两条不同的落图路径，共用同一套组件库 `gTV3VdC6a5e9vpkRHIZSXA`：

| 策略 | 平台 | 落图方式 | Slot 处理 | 失败处理 |
| --- | --- | --- | --- | --- |
| `assemble` | yushu / generic | 从组件库解析组件并逐项组装实例 | Slot 逐层同步 | 写失败即 `FAIL` |
| `copyTemplate` | zhikexing | 复制人工候选外壳，按业务适配内容区 | 允许写入真实实例公开 Slot 并回读 | 仅真实组件或布局能力失败时阻塞 |

`copyTemplate` 保留已调好的平台外壳与内容区尺寸。Slot 写入逐步验证，失败时保留候选并报告具体节点和错误；不得因为示例字段数量不同而停止。选择哪条路径由平台文件声明，不由业务字段决定。

## 3. 基线模板

历史默认模板位于组件库文件，仅在当前候选不可读取且平台组件完整性核验通过时作为后备外壳：

```text
Template / List Page / 智客星 / 1440 / 手动调整
node: 4892:34812
实际尺寸: 1366 x 768
```

- 名称中的 `1440` 是历史命名，不得据此改变画板宽度；后续新页面一律按实际 `1366 x 768`。
- 模板重命名由人工单独处理，不在生成任务中改动。
- 当前列表优先读取 `5468:3233`，再读取人工原稿 `5408:13969`；历史模板 `4892:34812` 只在前两者不可读取时核验使用。所有来源都必须核对实际 `1366 x 768` 尺寸和智客星组件引用。
- 该模板及下述人工调整版当前均为 `Candidate`，不是 Golden Sample。使用时必须解析专属 `Navigation / HeaderMenu / 智客星 Header`；不得回退到 `Yushu Header-V2`。

当前人工调整候选模板：

```text
Template / List Page / 智客星 / 1366 / 手动调整
node: 5408:13969
所在 Page: 🌟 测试 qifu-detail-page (5391:1221)
实际尺寸: 1366 x 768
status: Candidate
```

- 它是当前人工确认的视觉与布局参考；其精确尺寸、文字层级、间距与生成门禁见 `skills/qifu-list-page/references/zhikexing-manual-template-contract.md`。
- 仅可在用户要求对比或候选复现时并列复制，复制结果必须命名 `Candidate / ...`，不得改名为 Golden Sample 或写入正式基线登记。
- 任何候选升级前，必须同时满足：Header/SideNavigation 不含 `yushu`、`毓数`、`鲸数` 或 `QBI` 命名/主组件引用；新增或改写的可见文本均保留本地 `textStyleId`；核心控件仍为真实实例；同尺寸截图经人工视觉确认。

当前复现参考：`Candidate / List Page / 智客星 / 1366 / 手动调整复现`（node `5468:3233`，同 Page，`1366 x 768`）。优先以它的 Header、侧栏、业务导航、内容卡片和本地文本样式作为视觉参考；其中的菜单选中项、7 个筛选、9 列和多选变体均是示例，不是业务字段或固定矩阵。源画板保持 Candidate 且不可覆盖。

历史高级筛选候选：

```text
Zhikexing List / Advanced Filter / 7 Filters / 8 Columns / Non-selectable
node: 5425:2083
所在 Page: 🌟 测试 qifu-detail-page skill (5391:1221)
实际尺寸: 1440 x 900
```

- 此历史候选可供对应业务对照，但其中“7 个筛选、两行筛选区、8 列、无多选框”不是智客星通用门槛。不得因其名称、视觉或历史运行记录而跳过当前模板完整性检查。
- 不得改动该模板、既有 `Basic Table` 实例或任何组件母版。
- 业务字段数、列数或多选状态不同时，按 PageSpec 调整真实实例；仅在组件或布局能力实际失败时报告具体阻塞。

## 4. 页面外壳

- 顶部栏 48px，使用专属智客星 Header 的品牌、帮助、通知、头像和用户信息；不重新绘制 Logo 或用户区。
- 侧栏宽 200px，底部保留 40px 的收起控制区，收起图标为已有 16px 图标实例。
- 一级菜单高 44px，二级菜单高 40px。一级菜单有真实图标，二级菜单不显示图标。
- 当前叶子菜单使用既有品牌色文字、浅色背景和右侧绿色指示条；当前路径祖先使用品牌色文字与图标。
- **选中祖先菜单**: 只要一级菜单的任一后代是当前叶子菜单，该一级菜单的标题、前置图标和展开指示器都必须绑定智客星主题色；不能只高亮二级叶子菜单而遗漏一级标题或图标。
- **展开/收起图标状态**: 选中祖先使用基线模板中对应的“已选中 + 展开”指示器实例；未选中父菜单使用对应的“未选中 + 收起”指示器实例。两种状态必须来自不同的已存在状态实例或已解析 Variant，不得通过旋转同一个箭头、在实例外叠图标或只修改颜色伪造。
- 未选中菜单的标题、前置图标和收起指示器使用既有中性色；不得直接填充绿色或改用别的平台变量。

## 4a. 专属全局 Header

- 组件集：`Navigation / HeaderMenu / 智客星 Header`，当前组件节点 `5517:2109`；通过真实 `INSTANCE` 使用，禁止分离实例或重画。
- 变体属性：`Items=0` 至 `Items=8`。用户未明确给出全局一级菜单时，固定使用 `Items=0`，仅显示智客星品牌与右侧标准操作，不自行补菜单。
- `Items=1` 至 `Items=5` 的既有菜单顺序是：客户中心、任务中心、质检管理、我的申请、我的排名；首项为选中状态。使用 `Items=6` 至 `Items=8` 前必须获得对应业务菜单名称，不能把“菜单6/7/8”作为正式页面文案。
- 页面仍按 `copyTemplate` 复制人工基线。仅当复制页发现旧 Header、Header 缺失或 Header 平台不完整时，允许将完整 Header 替换为上述专属实例；替换后必须回读 `mainComponent`、`Items`、1366 x 48 尺寸和右侧操作可见性。
- Header 内所有可见文字必须绑定既有本地 Text Style。修改菜单文案时只能保留或复用原有 `textStyleId`，不得手动创建字体或文本样式。

## 6. 筛选与表格差异

固定的是智客星 `1366 x 768` 外壳和 `216,152,1134,600` 内容卡片；筛选和表格在其 `1086px` 可用宽度内按 PageSpec 动态适配：

- 筛选字段、控件、触发方式与先后顺序来自业务规格。保留真实带标题 Filter Item；按可用宽度排成一行或两行，超过可见容量时优先使用真实展开筛选能力，不将确认字段悄悄丢弃。
- 表格列、行和操作来自业务规格；列宽按文本与优先级分配，表头和每行共用同一宽度数组。表头与数据行沿用真实组件的 44px 密度，表格高度随行数和分页变化。
- `selection` 只由 `tableSelection` 决定；候选的 `on`、`off` 状态都不是默认业务结论。分页与记录数依业务数据及页面状态调整。
- 状态使用真实 Tag；颜色与文案由业务状态决定，文本绑定本地样式。

`5408:13969` 与 `5468:3233` 的筛选数和 9 列仅是视觉样例；`5425:2083` 的 7 筛选、8 列虽然匹配某一业务，却是 `1440 x 900`，不能改变当前尺寸。允许在真实 Filter Bar-V2、Table Shell-V2 等实例的公开 Slot 中替换字段和行；每步回读 `mainComponent`、变体、数量、尺寸、文字样式及 1x 截图。只有真实组件缺失、写入失败或在不丢失必需字段的情况下无法布局时才报告具体阻塞，不因旧候选字段矩阵不符而阻塞。不得修改母版、分离实例、手绘核心控件或升级 Candidate 为 Golden Sample。

## 7. 变量与文字

- 品牌色 `#00B578`、菜单选中背景、文字、边框和表格底色均继承复制模板中的变量绑定。
- 标题、筛选 Label、表头、表格正文和链接继承原实例的文本样式；不可改成未绑定的 MiSans 或裸字。
- 一级菜单图标在选中祖先或当前项中必须实际呈现品牌色，而不仅是完成 INSTANCE_SWAP。
- 侧栏验收必须逐项回读：当前叶子有浅色背景和右侧指示条；每个选中祖先的标题、前置图标、展开指示器均为主题色和展开状态；每个未选中父菜单的标题、前置图标、收起指示器均为中性色和收起状态。

sideAncestorsActive=[客户添加]
